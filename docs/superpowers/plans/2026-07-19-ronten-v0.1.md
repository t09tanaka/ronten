# ronten v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ronten`, a single-binary CLI that presents an agent's code changes as reviewable "concerns" in a localhost web UI and returns the human's review as machine-readable JSON.

**Architecture:** Rust CLI (clap) computes `git diff <base>...HEAD` itself, maps diff hunks to agent-supplied concerns, serves an embedded Svelte 5 SPA over a token-protected localhost axum server, blocks until the reviewer submits/aborts/times out, then prints result JSON to stdout and exits with a contract exit code.

**Tech Stack:** Rust (axum 0.8, tokio, clap 4, serde, schemars 1, rust-embed 8, chrono, humantime, rand, open), Svelte 5 + Vite + TypeScript + Vitest.

**Spec:** `docs/superpowers/specs/2026-07-19-ronten-v0.1-design.md` — read it before starting any task.

## Global Constraints

- All UI copy, docs, code comments, and commit messages are **English**.
- **stdout is machine-readable only** (result JSON, schemas). All logs/progress go to stderr.
- Exit codes: `0` approved, `1` request-changes, `2` aborted (incl. Ctrl-C), `3` timeout, `10` invalid usage or invalid concerns JSON, `11` unresolvable base ref, `12` not a git repository, `13` empty diff, `14` git execution failure. clap's default exit 2 on usage errors MUST be overridden to 10 (2 is reserved for "aborted").
- Server binds `127.0.0.1` only. All API routes require the 128-bit session token.
- Unknown fields in concerns JSON are ignored silently (serde default behavior — do NOT add `deny_unknown_fields`).
- Reserved concern id: `_unmapped`. Input containing it (or duplicate ids) is an input error (exit 10).
- No virtual scrolling. Hunks with > 200 rendered lines are collapsed by default in the UI.
- Rust edition 2021; binary/crate name `ronten`. Run `cargo fmt` before every commit.

```rust
use clap::Parser;
use std::path::PathBuf;
use std::time::Duration;

pub mod exitcode {
    pub const APPROVED: u8 = 0;
    pub const REQUEST_CHANGES: u8 = 1;
    pub const ABORTED: u8 = 2;
    pub const TIMEOUT: u8 = 3;
    /// Invalid usage or invalid concerns JSON.
    pub const INPUT: u8 = 10;
    pub const BAD_BASE: u8 = 11;
    pub const NOT_A_REPO: u8 = 12;
    pub const EMPTY_DIFF: u8 = 13;
    pub const GIT_FAILED: u8 = 14;
}

#[derive(Parser, Debug)]
#[command(name = "ronten", version, about = "Concern-based PR review viewer")]
enum Cli {
    /// Start a review session for `git diff <base>...HEAD`
    Review(ReviewArgs),
    /// Print JSON Schemas for the input/output contract
    Schema(SchemaArgs),
    /// Launch the UI with an embedded sample session (no git required)
    Demo(DemoArgs),
}

#[derive(clap::Args, Debug)]
struct ReviewArgs {
    /// Base ref; the diff reviewed is `git diff <base>...HEAD`
    #[arg(long)]
    base: String,
    /// Path to concerns JSON; use `-` for stdin
    #[arg(long)]
    concerns: String,
    /// Also write the result JSON to this file
    #[arg(long)]
    out: Option<PathBuf>,
    /// Bind port (0 = OS-assigned)
    #[arg(long, default_value_t = 0)]
    port: u16,
    /// Do not open the browser automatically
    #[arg(long)]
    no_open: bool,
    /// Session display name (defaults to current branch name)
    #[arg(long)]
    title: Option<String>,
    /// Exit 3 if nothing is submitted within this duration (e.g. "30m")
    #[arg(long, value_parser = humantime::parse_duration)]
    timeout: Option<Duration>,
}

#[derive(clap::Args, Debug)]
struct SchemaArgs {
    /// Print only the input (concerns) schema
    #[arg(long, conflicts_with = "output")]
    input: bool,
    /// Print only the output (result) schema
    #[arg(long)]
    output: bool,
}

#[derive(clap::Args, Debug)]
struct DemoArgs {
    #[arg(long, default_value_t = 0)]
    port: u16,
    #[arg(long)]
    no_open: bool,
}

fn main() {
    let cli = match Cli::try_parse() {
        Ok(cli) => cli,
        Err(e) => {
            // --help/--version are "errors" in clap terms but must exit 0
            if e.use_stderr() {
                eprintln!("{e}");
                std::process::exit(exitcode::INPUT as i32);
            }
            print!("{e}");
            std::process::exit(0);
        }
    };
    let code = match cli {
        Cli::Review(_) | Cli::Schema(_) | Cli::Demo(_) => {
            eprintln!("not implemented yet");
            exitcode::INPUT
        }
    };
    std::process::exit(code as i32);
}
```

- [ ] **Step 3: Implement the parser.** Line-by-line state machine:
  - `diff --git ` starts a new `FileDiff` (status starts `Modified`; paths provisionally from the `--- a/…` / `+++ b/…` lines, stripping the `a/`/`b/` prefixes; `/dev/null` ⇒ `None`).
  - Header lines: `new file mode` ⇒ `Added`; `deleted file mode` ⇒ `Deleted`; `rename from X` / `rename to Y` ⇒ `Renamed` + set paths (these are authoritative for renames, no `a/` prefix to strip); `Binary files … differ` or `GIT binary patch` ⇒ `Binary`.
  - Hunk header: regex-free parse of `@@ -{old_start}[,{old_count}] +{new_start}[,{new_count}] @@[ section]` (omitted count = 1). Track running `old_no`/`new_no` counters seeded from the starts; ` ` advances both, `-` only old, `+` only new; `\` lines (no-newline marker) are skipped.
  - Content after the first character marker is stored verbatim (tabs preserved).

```rust
pub fn resolve_mapping(files: &[FileDiff], input: &ConcernsInput) -> Mapping {
    let mut warnings = Vec::new();
    let mut claimed: std::collections::HashSet<HunkRef> = Default::default();
    let mut concerns = Vec::new();
    for c in &input.concerns {
        let mut refs: Vec<HunkRef> = Vec::new();
        for loc in &c.locations {
            let side = loc.side.unwrap_or(Side::New);
            let mut matched = false;
            for (fi, file) in files.iter().enumerate() {
                let path = match side { Side::New => file.new_path.as_deref(), Side::Old => file.old_path.as_deref() };
                if path != Some(loc.path.as_str()) { continue; }
                if file.hunks.is_empty() && loc.start.is_none() && loc.end.is_none() {
                    refs.push(HunkRef { file: fi, hunk: None });
                    matched = true;
                    continue;
                }
                for (hi, h) in file.hunks.iter().enumerate() {
                    let (hs, hc) = match side { Side::New => (h.new_start, h.new_count), Side::Old => (h.old_start, h.old_count) };
                    let he = if hc == 0 { hs } else { hs + hc - 1 };
                    let ls = loc.start.unwrap_or(1);
                    let le = loc.end.unwrap_or(u32::MAX);
                    if hs.max(ls) <= he.min(le) {
                        refs.push(HunkRef { file: fi, hunk: Some(hi) });
                        matched = true;
                    }
                }
            }
            if !matched {
                let range = match (loc.start, loc.end) {
                    (Some(s), Some(e)) => format!(":{s}-{e}"),
                    (Some(s), None) => format!(":{s}-"),
                    _ => String::new(),
                };
                warnings.push(format!("location matched no hunks: {}{}", loc.path, range));
            }
        }
        refs.sort_by_key(|r| (r.file, r.hunk));
        refs.dedup();
        claimed.extend(refs.iter().copied());
        concerns.push(MappedConcern { id: c.id.clone(), hunks: refs });
    }
    let mut unmapped = Vec::new();
    for (fi, file) in files.iter().enumerate() {
        if file.hunks.is_empty() {
            let r = HunkRef { file: fi, hunk: None };
            if !claimed.contains(&r) { unmapped.push(r); }
        } else {
            for hi in 0..file.hunks.len() {
                let r = HunkRef { file: fi, hunk: Some(hi) };
                if !claimed.contains(&r) { unmapped.push(r); }
            }
        }
    }
    Mapping { concerns, unmapped, warnings }
}
```
